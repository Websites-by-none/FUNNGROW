# FUNNGROW Website

A responsive React and Vite homepage for Teenlancers and companies. The site uses Tailwind CSS v4, Framer Motion and Lucide React.

## Run locally

Requirements: Node.js 20 or newer and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173`.

## Production build

```bash
npm run build
npm run preview
```

## Content and assets

- FUNNGROW app screenshots and the matching app mark are local copies of assets from `funngro.com`.
- The supplied full wordmark was not present in the starter workspace; the lockup currently uses the matching official app mark alongside the FUNNGROW text.
- Campaign examples, platform figures, safety details, contact information and social URLs were checked against the official FUNNGROW site.
